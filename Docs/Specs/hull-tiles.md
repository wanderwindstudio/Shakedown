# Hull tiles — M1b Blender brief

This is the corner-based contract used by `HullTileLookup`, `HullTiles` and `ShipVisuals`. There are **22 base patterns**, including empty and full, and **256 case mappings**. The exact mapping and all 48 orientation transforms are in [hull-tile-lookup.json](hull-tile-lookup.json). IDs and bit order are stable; do not renumber them.

## Dimensions, axes and pivot

Each tile's **domain is a 2.5 × 2.5 × 2.5 m cube**, with its pivot at **(0,0,0), the grid corner**, and bounds −1.25…+1.25 m on X/Y/Z. A partial tile's actual mesh bounds can be smaller: do not rescale or recenter it. Unity +X is right, +Y up, +Z forward. The yard's corner `(cx,cy,cz)` is at `2.5 * (cx−0.5, cy, cz−0.5)` metres.

Eight octants meet at the pivot. Bit index is `b = x + 2*y + 4*z`, where each coordinate is 0 for the negative half and 1 for the positive half. Thus bits 0…7 have signs `---, +--, -+-, ++-, --+, +-+, -++, +++`. Set bit = occupied cell, regardless of its part type. Fixed pieces and locked hulls influence the pattern but replace their own octants with their own meshes.

Use **metre-sized, flat-shaded geometry**. The placeholder bevel is **c = 0.5 m**. At runtime Lars can change Chamfer Size on the ShipYard component from 0 to 1 m. That slider regenerates placeholders; future authored FBX tiles will need a chosen matching bevel size, rather than automatic deformation.

## Boundary and seam contract (exact)

Each occupied octant uses signed coordinates `u,v,w` from **0 to 1.25**, directed from the pivot into that cell. Start with that box, then:

- If the face neighbours across both axes `a` and `b` are empty, keep only `a + b >= c`. This bevel cuts **into occupied volume**, with no intrusion into an empty cell.
- If all three face neighbours are empty, also keep `u+v+w >= min(2*c, 1.25)`. This provides the small triangular corner face at c=0.5.
- Keep concave corners sharp. Do not bridge diagonal-only contacts or fill their empty octants.
- Remove coincident internal faces between occupied octants; where their bevel cuts differ, keep only the uncovered part of the interface. This closes stepped joins without overlapping coplanar surfaces.
- **Never cap the tile's six outer domain faces.** These are continuation boundaries, not exposed hull. At x/y/z = ±1.25, keep the cross-section exactly where the equations above put it. Along a domain face, exposed contours lie on the remaining coordinate-zero lines, with two-axis bevel endpoints at `(0, ±0.5)` and `(±0.5, 0)` where both corresponding face neighbours are empty. The triangular corner cut never crosses an outer domain face.
- On each of the **12 outer cube edges**, a surface crosses at its midpoint (variable coordinate 0) **if and only if** the endpoint bits differ. No crossing exists if the two endpoint bits match. Each entry below lists its crossing points. These are edge contacts, not permission to add boundary caps.

At hollow fixed-piece interfaces, the visual layer separately closes the hull cell face (for example, the floor under a door opening). Do not bake these supplemental junction faces into a base tile.

Keep all border vertices at the exact coordinates above. Do not move them for decoration, smooth them across a sharp edge, add rim thickness, or duplicate a neighbour's cap. Opposite sides of neighbouring tiles then share the same profile. Future details must remain inside the occupied envelope, or intrude into empty space by no more than 0.25 m; these placeholders intrude **0 m**.

## Paint and mesh naming

The simplest clean colour rule is **cell ownership**: each triangle belongs entirely to one occupied octant and uses that cell's paint. Colour borders are sharp on octant planes; colours are not averaged across cells. Keep each octant as a separate mesh node even when its surface touches another octant.

Export `HullTile_00.fbx` … `HullTile_21.fbx`. Root name: `HullTile_XX`, with identity transform at the common pivot. Mesh children: **`HullTile_XX_o0` … `HullTile_XX_o7`**, only where that octant has exposed triangles. All children have identity transforms and share the root origin. These are the mesh names generated by the code and the layout of `HullTiles.Octants[tile, bit]`. Empty/full tiles can have an empty root with no mesh children. Real-art asset binding is future work; M1b deliberately uses generated placeholder meshes, not an automatic FBX importer.

## Orientations applied by the lookup

The lookup uses 48 signed axis permutations: 24 rotations and 24 reflections. These tile symmetries are **separate from the 0…23 placed-part rotation index**. Hull placement rotation is ignored while auto-shaping is enabled.

Permutations, in order: `XYZ, XZY, YXZ, YZX, ZXY, ZYX`. Within each, sign index s = 0…7 negates input X/Y/Z when s has bit 0/1/2 set. Symmetry index = `8*permutationIndex + s`. The transform maps canonical input basis column i to output axis `permutation[i]`, multiplied by that sign; it acts about the tile pivot. Canonical pattern is the smallest integer in the pattern's orbit; the lookup picks the first symmetry that maps it to the requested pattern. Reflections reverse triangle winding, and the renderer corrects it. Build the canonical geometry once; do not bake 48 variants in Blender.

## FBX export/import settings

In Blender: Metric, Unit Scale **1.0**; 1 Blender unit = 1 m. Model with Blender X = Unity X, Blender Z = Unity Y and Blender −Y = Unity +Z. Apply object Rotation and Scale, retain the common origin, export Selected Objects (meshes/empty root only), Scale **1**, Forward **−Z**, Up **Y**, Apply Unit enabled, Apply Scalings **FBX Units Scale**, Apply Modifiers enabled, Smoothing **Face**, animation/cameras/lights disabled. Recalculate outward normals and triangulate deliberately; use hard normals at faceted edges. No subdivision or automatic boundary welding across octant ownership.

In Unity 6000.3: Scale Factor **1**, Convert Units on, Bake Axis Conversion on, Normals **Import**, mesh compression off, **Read/Write enabled** (the chunk combiner reads vertices), Generate Colliders off (the grid builds collision). Import a calibration tile first: pivot zero, outer domain 2.5 m, canonical octants and axis signs as above, identity root scale. FBX conversion must pass that check before replacing placeholders; no authored FBX round-trip is claimed in M1b. See [Unity's model import reference](https://docs.unity.com/en-us/engine/6000.3/manual/assets-and-media/asset-types/models/importing/fbximporter-model) and [Blender's FBX manual](https://docs.blender.org/manual/en/5.4/files/import_export/fbx_legacy.html).
